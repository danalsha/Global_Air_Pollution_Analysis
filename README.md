## Project Overview

This project analyzes a global air pollution dataset to predict Air Quality Index (AQI) values using machine learning. Two regression models are built and compared — Linear Regression as a baseline and Random Forest as the main model. The project also includes an interactive Streamlit interface where users can input pollutant readings and receive a predicted AQI value and category.

The project is aligned with:
- **SDG 3** — Good Health and Well-Being
- **SDG 11** — Sustainable Cities and Communities

---

## Dataset

**Global Air Pollution Dataset** — sourced from Kaggle
- 23,463 cities across 175 countries
- Features: CO AQI Value, Ozone AQI Value, NO2 AQI Value, PM2.5 AQI Value
- Target: Overall AQI Value (continuous regression task)

Dataset link: https://www.kaggle.com/datasets/hasibalmuzdadid/global-air-pollution-dataset

## How to Run

### Step 1 — Clone the repository
```bash
git clone https://github.com/danalsha/Global_Air_Pollution_Analysis.git
cd Global_Air_Pollution_Analysis
```

### Step 2 — Install dependencies
```bash
pip install pandas numpy matplotlib seaborn scikit-learn joblib streamlit
```

### Step 3 — Run the notebook
Open `Global_Air_Pollution_Analysis_Final.ipynb` in Jupyter and run all cells from top to bottom:
```
Kernel → Restart & Run All
```
This will generate `rf_model.joblib` and `scaler.joblib` which are required for the Streamlit app.

### Step 4 — Launch the Streamlit app
```bash
streamlit run app.py
```
Then open your browser at `http://localhost:8501`

## Results

| Model | MAE | RMSE | R² |
|---|---|---|---|
| Linear Regression | 4.80 | 8.77 | 0.9758 |
| Random Forest | 0.23 | 2.70 | 0.9977 |

Random Forest outperformed Linear Regression across all metrics. PM2.5 was identified as the dominant predictor of overall AQI, accounting for approximately 98% of the Random Forest feature importance.

---

## Key Findings

- PM2.5 has a 0.984 correlation with overall AQI — the strongest of all pollutants
- A significant proportion of cities worldwide have AQI values above 100 (unsafe threshold)
- Ozone and PM2.5 behave independently, driven by different pollution sources
- Random Forest captures non-linear pollutant relationships better than Linear Regression
- Memory optimization reduced dataset size from 10.89 MB to 1.87 MB (82.9% reduction)
